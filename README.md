# Multi-Company URL Shortener Service

A multi-tenant URL Shortener service built with Laravel 10. The platform allows multiple companies (clients) to register, invite team members, generate short URLs, monitor clicks, and analyze link activity across date intervals.

---

## Features

- **Multi-Company Architecture:** Each company operates with independent users and scoped URL tracking.
- **Role-Based Access Control:**
  - **SuperAdmin:** Platform-wide oversight. Can view all companies, global short URLs, overall clicks, and invite new company Admins. Cannot generate short URLs.
  - **Admin:** Company administrator. Can view all company short URLs, generate short URLs, and invite other Admins or Members into their own company.
  - **Member:** Team member. Can generate short URLs and view only the URLs generated by themselves.
- **Public URL Resolution & Click Tracking:** Publicly accessible route `/{code}` redirects to the original destination with HTTP 302 while incrementing visit counts and recording click analytics.
- **Date Interval Analytics & CSV Export:** Filter URLs and click performance by `Today`, `Last Week`, `Last Month`, and `This Month`, with one-click CSV export.
- **Automated Test Suite:** 100% test coverage for all requirements outlined in the task specification.

## Local Setup & Installation

### 1. Clone the Repository
```bash
git clone <repository-url>
cd url-shortener
```

### 2. Install Dependencies
```bash
composer install
```

### 3. Environment Configuration
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

Generate the application encryption key:
```bash
php artisan key:generate
```

Configure your database connection in `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=url_shortener
DB_USERNAME=root
DB_PASSWORD=
```
*(Make sure the database `url_shortener` is created in your MySQL server).*

### 4. Run Migrations & Seeders
Run database migrations and seed default roles and the SuperAdmin account:
```bash
php artisan migrate:fresh --seed
```

### 5. Start the Development Server
```bash
php artisan serve
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
